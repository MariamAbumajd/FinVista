# Finvista Management System 🏦

A professional management system designed to streamline ATM operations and manage customer bookings efficiently. 

## Overview
Finvista acts as an intermediary system to organize ATM usage. It provides a dashboard for employees to track transactions and a booking system for customers to reserve their turn.

## Tech Stack
- **Backend:** Node.js, SQLite
- **Frontend:** HTML, CSS, JavaScript
